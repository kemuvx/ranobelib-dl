# ranobelib-dl

Скрипт на Python для скачивания ранобэ с ranobelib.me в формате EPUB с иллюстрациями и обложкой.

## Установка

 
1. Скачать и распаковать архив со скриптом либо клонировать репозиторий (если установлен Git):
```bash
git clone https://github.com/kemuvx/ranobelib-dl.git
cd ranobelib-dl
```

2. Создать и активировать виртуальное окружение в папке со скриптом (необязательно):
```bash
python -m venv .venv
source .venv/bin/activate
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

## Использование

1. Запустить:
```bash
python ranobe-downloader.py
```
2. Ввести URL ранобэ и номер тома.
   
3. Выбрать перевод если есть.
   
## Настройка (config.json)

Все настраиваемые параметры вынесены в файл `config.json`:
- `time_to_sleep` (по умолчанию `0.5`): задержка между запросами к главам в секундах.
- `add_folder` (по умолчанию `true`): сохранять ли книги в отдельные папки с названием ранобэ. Чтобы сохранять в текущую директорию, укажите `false`.
- `filter_ads` (по умолчанию `true`): автоматическое удаление рекламы, ссылок на соцсети и водяных знаков из текста.
- `check_ad_banners` (по умолчанию `true`): обнаружение и интерактивная проверка рекламных баннеров-картинок.
- `banner_min_repeats` (по умолчанию `2`): порог повторений баннера для проверки.
- `review_timeout` (по умолчанию `10.0`): таймаут интерактивного выбора действия с баннером (в секундах).
- `default_review_action` (по умолчанию `"1"`): действие по таймауту или нажатию Enter (`"1"` — удалить из всех глав, `"2"` — оставить).
- `token` (по умолчанию `null`): токен авторизации (также поддерживается в `.env` как `RANOBELIB_AUTH_TOKEN="ваш_токен"`).
- `headers`: HTTP-заголовки запросов (User-Agent и др.).

### Результат
- В рабочей папке или в папке с названием ранобэ появится EPUB-файл: "Название Том №.epub".
  
- Во время работы создаются папки для обложки и изображений (их можно удалить после завершения).

## Инструкция как получить токен
### Первый способ:
1. Зайти на сайт [ranobelib.me](https://ranobelib.me).

2. Войти в аккаунт.

3. Открыть инструменты разработчика (F12) и перейти на вкладку Console.

4. Ввести в консоль команду:
```
console.log(JSON.parse(localStorage.auth).token.access_token);
```
- Если ранее никогда ничего не вводили в консоль, то может появиться предупреждение, согласно которому необходимо напечатать текст разрешения.

5. Скопировать появившийся токен.
### Второй способ:
1. Зайти на сайт [ranobelib.me](https://ranobelib.me).

2. Войти в аккаунт.

3. Открыть инструменты разработчика (F12) и перейдите в раздел локального хранилища:

    - Вкладка "Application"

    - Раздел "Local Storage"

    - Выбрать "ranobelib.me"

4. Скопировать значение access_token из auth -> token.
